## Notes

- **`% of Project` estimates** are rough approximations of how much of this project's functionality depends on each library. The estimates are qualitative and not mutually exclusive — for example, React is a core dependency of Next.js, so their percentages overlap.
- **TypeScript** and **DefinitelyTyped (`@types/*`)** packages are compile-time tools only and contribute 0% to the deployed runtime.
- **Development-only dependencies** are used during the build/development process and are not shipped in the production bundle.
- License information was sourced from each package's repository at the time of this writing. Please verify current licenses before redistribution.
